# Hallucination & Citation Verification Framework for RAG Applications

## Overview

An AI-powered framework designed to detect unsupported claims and verify citations in answers generated by Retrieval-Augmented Generation (RAG) applications.

## Problem Statement

LLMs can generate answers containing hallucinated or unsupported information, even when connected to external documents. This project aims to evaluate the factual support behind generated answers using retrieved evidence.

## Planned Features

- PDF and text document ingestion
- Text chunking and embedding generation
- Semantic search using FAISS
- RAG-based answer generation
- Claim extraction from generated answers
- Claim-level evidence verification
- Citation validation
- Classification of claims as Supported, Unsupported, or Uncertain

## Technology Stack

- Python
- Streamlit
- PyMuPDF
- Sentence Transformers
- FAISS
- Google Gemini API

## Project Status

Initial development — environment setup completed.
